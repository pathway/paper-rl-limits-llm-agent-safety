**Phases, and where evaluation belongs.** A setting is in the training phase when the weights are updated from a reward. It is in the deployment phase when the model is frozen and run. We place evaluation in the deployment phase. During an evaluation no weight is updated, but the model adapts in context, which the designer does not control (S5 fails); whatever the model optimises, it optimises in context. Evaluation differs from ordinary deployment in one way: a score is defined, and the agent can pursue it as it would pursue a reward. So we read an incident in an evaluation as a D-AGENT incident with a visible objective, and we count it as evidence about RL training only where the report itself describes training runs. In the title and abstract, deployed means this frozen-model phase; evidence from an evaluation bears on deployed products only indirectly, because products add safeguards that evaluations may leave out.
